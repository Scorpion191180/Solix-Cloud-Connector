# House photo textures

These assets are used by the interactive 3D house view.

- `front-reference.jpg`, `garden-reference.jpg`, `garage-gable-reference.jpg`, and
  `side-gable-reference.jpg` are resized, metadata-free copies of private photos
  supplied by the repository owner for this application.
- `facade-wall.jpg` and `roof-tiles.jpg` are seamless textures derived from those
  references with OpenAI ImageGen.

The reference photos remain copyrighted private material. Their inclusion here
does not grant a separate license for reuse outside this application.
